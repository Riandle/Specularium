## 观园里有什么

<CardGrid>
  <Card title="公开可读" icon="open-book">
    不需要注册，任何拿到链接的人都能读完全部文档。页面支持全文搜索、目录跳转和深色模式。
  </Card>
  <Card title="创作者在线编辑" icon="pencil">
    创作者打开 `/admin/`，用 GitHub 账号登录后直接在网页里写，保存后自动生成一次提交，不需要本地环境。
  </Card>
  <Card title="版本可追溯" icon="code-branch">
    所有文字都存在 GitHub 仓库里。谁在什么时候改了什么，随时能查、能对比、能回退。
  </Card>
  <Card title="讨论与反馈" icon="comment">
    每篇文档底部都有评论区，读者可以直接提问，创作者收到通知后回复。
  </Card>
</CardGrid>
