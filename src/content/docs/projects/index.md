这里放按项目组织的文档。**文件夹就是文档集**，可以任意往下嵌套：

```
projects/
  index.md                    ← 你正在看的这一页（总览）
  示例项目Alpha/              ← 一个项目（文档集）
    index.md                  ← 项目的封面页
    background.md
    会议记录/                 ← 再往下一层：子分组
      2026-11.md
```

侧边栏会自动按这个结构生成，项目文件夹的名字就是分组标题。

## 怎么新增

在后台新建文档，把「路径」字段填成你想放的层级：

| 想要的效果 | 路径填 |
| --- | --- |
| 新项目「beta」 | `beta` |
| 新项目 beta 的会议记录 | `beta/会议记录` |
| 项目下的子分组 | `beta/子分组` |

:::note[为什么文件夹用中文]
侧边栏分组名直接取文件夹名。用中文命名文件夹，新增项目时不用改任何配置，标题就是中文的
（代价是网址里会有百分号编码，浏览器地址栏仍显示中文）。

如果某个项目想要和文件夹名不同的标题，或要固定排序，就把 `astro.config.mjs` 里
`项目文档集` 那一组改成显式写法，见那里的注释。
:::

:::caution[示例内容]
这整组 `projects/` 是演示用的，确认结构合适后可以在后台删掉，换成真实项目。
:::
