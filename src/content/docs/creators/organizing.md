文档多了以后，平铺在一层里会很难找。观园支持用**文件夹**组织文档集，并且可以多层嵌套。

## 结论：用文件夹，不要用超链接凑

| 做法 | 效果 |
| --- | --- |
| **文件夹**（推荐） | 侧边栏自动出现嵌套分组，网址分层，上一页/下一页按集合顺序走 |
| 一篇文档 + 一堆链接 | 链接要手工维护，没有分组、没有顺序、搜索里和正文混在一起 |

单篇 + 链接不是不能用——它适合当**索引页**（比如本篇开场列个目录），但不适合当集合本身。

## 目录怎么摆

```
src/content/docs/projects/
  index.md                  ← /projects/          总览页
  示例项目Alpha/            ← 一个项目（文档集）
    index.md                ← /projects/示例项目Alpha/  项目封面页
    background.md           ← /projects/示例项目Alpha/background/
    会议记录/               ← 子分组
      2026-11.md            ← /projects/示例项目Alpha/会议记录/2026-11/
```

规律很简单：

- **一个文件夹 = 一个分组**，文件夹名就是侧边栏里的分组标题；
- 文件夹里的 `index.md` 是这个文件夹的**封面页**（没有它，这个网址就不存在）；
- 想再分组，就再建一层文件夹，层数没有硬限制（后台配置里给到 4–5 层）。

## 在后台怎么建

进「项目文档集」或「文档」栏目，点新建，在**「路径」字段**里写层级：

| 想要的效果 | 路径填 |
| --- | --- |
| 新项目 `beta` | `beta` |
| 项目 `beta` 的会议记录 | `beta/会议记录` |
| 已有项目下新建一篇 | `示例项目Alpha/新文档` |

「路径」决定了文件放在哪个文件夹，也决定了网址。**新建前先想好名字**，
因为改名会让文章网址变化，之前分享出去的链接会失效。

## 用中文命名文件夹

侧边栏分组标题直接取文件夹名，所以**用中文命名就能得到中文标题，而且新增项目不用改任何配置**。

代价只有一处：网址里会出现百分号编码，例如
`/projects/%E7%A4%BA%E4%BE%8B%E9%A1%B9%E7%9B%AEalpha/`。浏览器地址栏通常仍显示中文，
复制分享也没问题。另外文件夹名里的**英文会被转成小写**（`Alpha` → `alpha`），中文部分不受影响。

如果你更看重网址干净，可以用英文文件夹名，然后在 `astro.config.mjs` 的侧边栏里为它写一行中文标题
（写法见那里的注释）。

## 几条实践建议

- **项目文件夹用一个名字就别改了**：改名 = 换网址。
- **别把 `index.md` 当普通文章写**，它承担的是「这个集合的目录页」的角色，
  正文里用相对链接列出组内文档最省事：`[背景与目标](./background/)`。
- **集合别摊太深**：三层（项目 → 子分组 → 文档）已经够用，再深读者会迷路。
- **想要固定顺序**：在文档的「侧边栏排序」里填数字，越小越靠前。
