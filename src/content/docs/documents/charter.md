## 一、我们想营造什么

一个能安静读完一篇长文、也敢认真说不同意见的地方。讨论可以尖锐，对人要客气。

## 二、发言的基本约定

1. **就事论事**——批评观点，不评价人。
2. **给出依据**——引用来源时给出链接，不确定就写「我印象中是」。
3. **允许被说服**——改变想法不是丢脸，是这件事值得做。
4. **不搬私信**——私人对话未经同意不公开引用。

## 三、内容的归属

| 情况 | 约定 |
| --- | --- |
| 原创文档 | 版权归作者，观园获得展示授权 |
| 转载 | 必须注明原作者与原始链接 |
| 协作文档 | 默认允许他人修改，重大改动在评论区说明 |
| 图片 | 使用有授权的素材，注明来源 |

## 四、什么会被删除

- 人身攻击、骚扰、歧视性言论；
- 未经同意公开他人的隐私信息；
- 商业广告与刷屏内容；
- 明显违法或侵权的内容。

删除前会尽量说明理由；作者有异议，可以在评论区提出，由维护者复议。

## 五、维护者做什么

维护者负责站点运行、处理举报、合并改动，不替任何人决定该写什么观点。
所有维护动作（删文、封禁）都会留下记录，可查。
