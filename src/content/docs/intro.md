观园是我们存放与展示文档的地方。它首先是一个**公开的文档站**：任何人拿到链接都能阅读，
不需要注册，也没有付费墙。其次它是一个**轻量的协作工具**：创作者不用懂 Git，也不用装开发环境，
在网页上就能写、能改、能发布。

## 为什么用 GitHub 存文件

文档本身是普通的 Markdown 文件，存在 GitHub 仓库里。这样做的好处很直接：

- **不会丢**——每一次保存都是一次提交，历史永远在，改错了可以一键回退。
- **不用服务器**——站点由 GitHub Pages 免费托管，没有服务器要维护、没有数据库要备份。
- **能迁移**——内容就是一堆 `.md` 文件，哪天想换平台，拷走即可。

## 这个站怎么组织

| 栏目 | 放什么 | 谁能编辑 |
| --- | --- | --- |
| 文档 | 公约、项目说明、长期资料 | 有仓库写权限的创作者 |
| 创作者手册 | 怎么用后台、怎么写、怎么导入 Word | 同上 |
| 作品画廊 | 创作者的作品图与介绍 | 同上 |

## 读者能做什么

- 用顶部的搜索框全文检索（支持中文分词）。
- 用右侧目录在长文里跳转。
- 在文档底部留言讨论——留言会以 GitHub Discussions 的形式保存。
- 切换深色模式，长文阅读更舒服。
